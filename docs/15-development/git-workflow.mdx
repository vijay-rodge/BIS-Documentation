# Git Workflow & Collaboration

The project follows a **Trunk-Based / Feature Branch** workflow with mandatory pull request reviews.

```mermaid
gitGraph
    commit id: "v1.0.0-release"
    branch feature/dynamic-ingestion
    checkout feature/dynamic-ingestion
    commit id: "add dynamic pipeline"
    commit id: "add chd/ced catalogue"
    checkout main
    merge feature/dynamic-ingestion id: "merge PR #42" tag: "v1.1.0"
    branch fix/reranker-penalty
    checkout fix/reranker-penalty
    commit id: "dampen off-topic chunks"
    checkout main
    merge fix/reranker-penalty id: "merge PR #43" tag: "v1.1.1"
```

---

## Conventional Commit Messages

Commit messages must follow the Conventional Commits specification:
- `feat(agents)`: Add category disambiguation follow-up buttons.
- `fix(reranker)`: Apply 50% penalty on off-topic knowledge chunks.
- `docs(api)`: Update chat completion response schemas.
- `test(eval)`: Add scenario 8 safe refusal assertion.
