# Monitoring & Observability

Production monitoring provides real-time visibility into query latency, subagent execution paths, and error rates.

```mermaid
flowchart LR
    App[FastAPI Application] --> Logs[Structured JSON Logs]
    App --> Health[/api/v1/health]
    App --> Metrics[/metrics - Prometheus]
    Metrics --> PrometheusServer[Prometheus Server]
    PrometheusServer --> Grafana[Grafana Dashboard]
    Logs --> LogCollector[Elasticsearch / Loki]
```

## Alerting Thresholds
- **High Error Rate Alert**: Triggered if HTTP 5xx responses exceed **1%** over a 5-minute rolling window.
- **Latency Degradation Alert**: Triggered if P95 latency exceeds **2500 ms**.
- **Gemini Quota Warning**: Alerts operations team when 429 quota exhaustion is detected.
