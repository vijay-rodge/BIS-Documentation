# Environment Variables Reference

The platform is configured entirely via environment variables conforming to 12-Factor App methodology.

| Variable Name | Required | Default Value | Description |
| :--- | :---: | :--- | :--- |
| `PROJECT_NAME` | No | `"BIS Intelligent Assistant"` | Service branding displayed in Swagger UI. |
| `DATABASE_URL` | **Yes** | `"sqlite:///./bis_agent.db"` | PostgreSQL connection string or local SQLite URI. |
| `GEMINI_API_KEY` | No | `None` | Google Gemini API key for grounded generative synthesis. |
| `ADMIN_API_KEY` | **Yes** | `None` | Secret token required for administrative ingestion endpoints. |
| `CORS_ORIGINS` | No | `["*"]` | Allowed CORS origins (must restrict in production). |
| `LOG_LEVEL` | No | `"INFO"` | Logging verbosity (`DEBUG`, `INFO`, `WARNING`, `ERROR`). |
| `RATE_LIMIT_PER_MINUTE` | No | `60` | SlowAPI rate limit per IP for public endpoints. |
