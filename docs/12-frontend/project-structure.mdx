# Frontend Project Structure

```
frontend/
├── src/
│   ├── components/           # UI Components
│   │   ├── ChatInterface.tsx # Primary conversational container
│   │   ├── MessageList.tsx   # Message thread renderer
│   │   ├── MessageItem.tsx   # Individual message bubble with Markdown
│   │   ├── CitationBadge.tsx # Tier-1 source citation tag
│   │   ├── PreviewModal.tsx  # BSB Edge preview modal viewer
│   │   ├── ActionPills.tsx   # Interactive follow-up category buttons
│   │   └── LanguageBar.tsx   # Language selector (EN / HI / MR)
│   │
│   ├── hooks/                # Custom React Hooks
│   │   ├── useChat.ts        # Conversational state & API dispatcher
│   │   └── useSpeech.ts      # Voice input/output hooks
│   │
│   ├── services/             # Backend API Client
│   │   └── api.ts            # Axios client with interceptors
│   │
│   └── types/                # TypeScript Interfaces
│       └── chat.ts           # ChatMessage, Citation, Disambiguation types
```
