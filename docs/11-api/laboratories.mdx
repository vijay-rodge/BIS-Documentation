# Laboratories API Endpoints

### Find Laboratories by Standard
`GET /api/v1/laboratories/by-standard/{standard_number}`

#### Request Parameters
- **`standard_number`** *(path, required)*: Standard number (e.g., `IS 4151:2020`).
- **`city`** *(query, optional)*: Filter by city name.
- **`state`** *(query, optional)*: Filter by state name.
