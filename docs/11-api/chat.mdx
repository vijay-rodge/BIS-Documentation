# Conversational Chat API

### Process Chat Query
`POST /api/v1/chat/completions`

The core intelligent endpoint executing the multi-agent decision loop.

#### Request Payload
```json
{
  "query": "What standard applies to paint?",
  "context": {
    "language": "en"
  }
}
```
