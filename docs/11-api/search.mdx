# Search API Endpoints

### Product to Standard Search
`POST /api/v1/search/product`

#### Request Payload
```json
{
  "product_query": "marking paint for packaging",
  "limit": 5
}
```

#### Example Response (`200 OK`)
```json
{
  "query": "marking paint for packaging",
  "matches": [
    {
      "standard_number": "IS 138:2018",
      "title": "Ready Mixed Paint, Marking, for Packages and Petrol Containers",
      "department": "Chemical Department (CHD)",
      "relevance_score": 1.0,
      "preview_url": "https://standardsbis.bsbedge.com/BIS_Preview.aspx?id=IS_138_2018"
    }
  ]
}
```
