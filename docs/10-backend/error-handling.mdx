# Error Handling & Exception Management

The backend enforces standardized JSON error envelopes and prevents internal stack traces from leaking to clients.

```json
{
  "error": {
    "code": "STANDARD_NOT_FOUND",
    "message": "Indian Standard 'IS 99999' could not be resolved from authoritative repositories.",
    "status_code": 404,
    "timestamp": "2026-09-26T03:15:00Z"
  }
}
```

---

## Global Exception Handler

```python
# backend/api/errors.py
from fastapi import Request
from fastapi.responses import JSONResponse

class BISBaseException(Exception):
    def __init__(self, message: str, code: str = "INTERNAL_ERROR", status_code: int = 500):
        self.message = message
        self.code = code
        self.status_code = status_code

async def bis_exception_handler(request: Request, exc: BISBaseException):
    return JSONResponse(
        status_code=exc.status_code,
        content={
            "error": {
                "code": exc.code,
                "message": exc.message,
                "status_code": exc.status_code
            }
        }
    )
```
