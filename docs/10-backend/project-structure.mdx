# Backend Project Structure

The codebase is organized into cleanly separated functional layers:

```
backend/
├── agents/                   # Specialized multi-agent regulatory subagents
│   ├── orchestrator.py       # Master lifecycle orchestrator & memory
│   ├── query_agent.py        # Intent classifier & language detector
│   ├── standard_agent.py     # Standards discovery & catalog lookup
│   ├── product_agent.py      # Category disambiguation & product mapper
│   ├── mandatory_status_agent.py # Central gazette QCO verifier
│   ├── testing_agent.py      # Clause-level test methods & criteria
│   ├── laboratory_agent.py   # BIS & NABL testing lab locator
│   ├── hallmarking_agent.py  # Gold & silver HUID compliance
│   ├── evidence_agent.py     # Authority tier validator & scorer
│   └── response_agent.py     # Grounded response synthesis
│
├── api/                      # REST API endpoints & route handlers
│   ├── routes.py             # Route aggregator & chat router
│   ├── standards_routes.py   # Standards catalog endpoints
│   ├── lab_routes.py         # Laboratory search endpoints
│   └── search_routes.py      # Hybrid retrieval endpoints
│
├── config/                   # Configuration, settings, and constants
│   └── settings.py           # Pydantic BaseSettings environment loader
│
├── database/                 # Persistence layer
│   ├── models.py             # SQLAlchemy 2.0 ORM models
│   ├── connection.py         # Engine & session management
│   └── repositories/         # Repository pattern abstractions
│
├── ingestion/                # Data pipelines & seed data
│   ├── dynamic_pipeline.py   # On-demand standard ingestion engine
│   └── bis_seed_data.py      # Seed standard catalog
│
├── rag/                      # Grounding, search, and LLM engines
│   ├── llm_engine.py         # Google Gemini interface & circuit breaker
│   ├── hybrid_search.py      # Dense/keyword retrieval engine
│   ├── reranker.py           # Authority tier & topical reranker
│   └── citation_builder.py   # Official BSB Edge URL citation formatter
│
└── evaluation/               # Golden scenario benchmarking suite
    ├── evaluator.py          # Benchmark test harness
    └── scenarios.py          # 8 Golden Scenarios test definitions
```
